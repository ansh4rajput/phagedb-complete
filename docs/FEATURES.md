# PhageDB Feature Roadmap

## Implemented in this rebuild
- Public landing / repository overview
- Search and filters
- Detailed scientific phage profile
- QR sharing
- Citation text
- JSON / CSV / FASTA downloads
- Compare up to 3 phages
- Researcher submissions
- Draft / pending / verified / rejected states
- Curator queue
- Record completeness indicator
- Audit trail and basic versioning
- Print / PDF-friendly record
- Resources / publications / contact pages

## Highest-priority next production features
1. Supabase/Postgres + object storage
2. Institutional authentication / ORCID
3. File upload with checksums and immutable versions
4. Curator comments + evidence checklist
5. Controlled taxonomies and host vocabularies
6. Sequence QC, BLAST and duplicate detection
7. DOI / PubMed / GenBank integrations
8. Host-range explorer and geographic map
9. Public API keys + rate limits + documentation
10. Repository governance, licensing and preservation policy
